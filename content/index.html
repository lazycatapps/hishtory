hiSHtory 历史同步服务

在多台终端之间安全同步 Shell 命令历史，掌控你的终端记忆。

项目简介

hiSHtory 是一款支持端到端加密的 Shell 历史同步工具。本应用基于 linuxserver.io 提供的官方容器镜像，针对 Lazycat Cloud 平台进行了封装，让你可以轻松在自建环境中跨设备共享命令历史。

核心亮点
  • 跨设备历史同步，支持 macOS、Linux 及容器环境。
  • 端到端加密（E2EE），服务器无法读取真实命令内容。
  • 记录命令上下文，包括目录、主机名、返回值、执行耗时等信息。
  • 提供命令行查询与 `hishtory start-web-ui` 图形界面，便于检索历史。
  • 与 Lazycat Cloud 深度集成，快速完成应用安装和维护。

客户端安装

在需要同步的每台机器上任选以下方式安装 hiSHtory：

方式一：官方安装脚本（推荐）

curl https://hishtory.dev/install.py | python3 -

脚本会自动下载二进制文件、生成密钥、并写入 Shell Hook。

方式二：手动下载二进制

访问 GitHub Releases 下载适合的压缩包，将可执行文件放入 `~/bin` 或 `/usr/local/bin`，然后执行：

hishtory install
提示：首次安装会生成一个 Secret Key。请妥善保存，在其他设备使用 `hishtory init <密钥>` 加入同一同步组。

指向自建服务器

Lazycat Cloud 部署完成后，在每台设备的 `~/.zshrc` 或 `~/.bashrc` 中加入以下环境变量，并重新加载终端：

export HISHTORY_SERVER=https://hishtory.${LAZYCAT_BOX_NAME}.heiyu.space

通过 `echo $HISHTORY_SERVER` 验证配置是否生效，然后执行：

hishtory init <密钥>
hishtory status

确认 `Enabled: true` 且服务器地址正确，即可开始同步。

常用命令

  • 查看状态：
    hishtory status
  • 手动同步历史：
    hishtory reupload
  • 查询最近记录：
    hishtory query --tail 20
  • 按主机过滤：
    hishtory query --host <主机名>
  • 复杂条件搜索：
    hishtory query "docker run" hostname:production exit_code:0
  • 时间范围查询：
    hishtory query deploy before:2024-01-01
  • 启动 Web UI：
    hishtory start-web-ui

    命令执行后在浏览器打开提示的地址（默认 http://127.0.0.1:8000），即可图形化浏览历史。

  • 临时关闭/开启同步：
    hishtory syncing disable
    hishtory syncing enable
  • 检查/重新注入 Hook：
    hishtory install
小技巧：在命令前输入空格可跳过记录，适合临时执行敏感指令。

高级配置

hiSHtory 支持丰富的个性化设置，可通过以下命令管理：

hishtory config-get
hishtory config-set displayed-columns Hostname CWD Command ExitCode
hishtory config-set timestamp-format '2006/Jan/2 15:04'
hishtory config-add custom-columns git_remote \
'(git remote -v 2>/dev/null | grep origin 1>/dev/null ) && git remote get-url origin || true'
hishtory config-add displayed-columns git_remote
hishtory config-set filter-duplicate-commands true
hishtory config-set compact-mode true

验证与排查

快速验证同步

  1. 在机器 A 执行 `echo hello-from-A`。
  2. 运行 `hishtory reupload` 立即上传历史。
  3. 在机器 B 执行 `hishtory query 'hello-from-A'`，若能检索到则同步成功。

常见问题

  • 历史记录停滞：确认 Shell 配置仍然 `source ~/.hishtory/config.*`，必要时重新执行 `hishtory install`。
  • 服务器无法访问：检查网络连通性或联系 Lazycat Cloud 管理员确认服务状态。
  • 需要离线模式：安装时在脚本后追加 `--offline`。
  • 强制重建数据库：使用 `hishtory init --force <密钥>`。
  • 查看客户端日志：运行 `tail -f ~/.hishtory/hishtory.log`。
安全提示：密钥仅保存在客户端，请妥善保管。若需要临时禁用同步，可执行 `hishtory syncing disable`。

Overview

hiSHtory is an end-to-end encrypted shell history synchronizer. This Lazycat Cloud package wraps the official linuxserver.io container so you can privately share command history across devices with minimal setup.

Highlights
  • Sync history across macOS, Linux, and container environments.
  • End-to-end encryption ensures the server never sees your raw commands.
  • Stores rich context such as working directory, hostname, exit code, and runtime.
  • Provides both CLI search and a convenient `hishtory start-web-ui` interface.
  • Optimized for Lazycat Cloud, enabling quick deployment and maintenance.

Install the Client

Install hiSHtory on every machine that should participate in syncing:

Option 1: Official installer (recommended)

curl https://hishtory.dev/install.py | python3 -

The script downloads the binary, generates a secret key, and injects shell hooks automatically.

Option 2: Manual download

Visit GitHub Releases, pick the build for your OS, place the binary in your PATH, then run:

hishtory install
Note: The first installation prints a Secret Key. Reuse it on other machines with `hishtory init <secret>`.

Point to Your Server

After deploying the Lazycat Cloud service, append the environment variable below to each shell profile (`~/.zshrc`, `~/.bashrc`) and reload your terminal:

export HISHTORY_SERVER=https://hishtory.${LAZYCAT_BOX_NAME}.heiyu.space

Verify with `echo $HISHTORY_SERVER`, then run:

hishtory init <secret>
hishtory status

When `Enabled: true` and the server URL matches, syncing is ready.

Essential Commands

  • Status overview:
    hishtory status
  • Force upload:
    hishtory reupload
  • Tail latest entries:
    hishtory query --tail 20
  • Filter by host:
    hishtory query --host <hostname>
  • Compound searches:
    hishtory query "docker run" hostname:production exit_code:0
  • Time range filters:
    hishtory query deploy before:2024-01-01
  • Launch the Web UI:
    hishtory start-web-ui

    Open the prompted URL (defaults to http://127.0.0.1:8000) to explore history visually.

  • Toggle syncing:
    hishtory syncing disable
    hishtory syncing enable
  • Reinstall hooks:
    hishtory install
Tip: Prefix a command with a space to skip recording sensitive operations.

Validation & Troubleshooting

Verify Sync

  1. Run `echo hello-from-A` on machine A.
  2. Execute `hishtory reupload` to push entries immediately.
  3. On machine B run `hishtory query 'hello-from-A'`; seeing the command confirms success.

Common Issues

  • No new entries: Ensure shell profiles still source `~/.hishtory/config.*`; rerun `hishtory install` if needed.
  • Server unreachable: Check network reachability or contact your Lazycat Cloud administrator.
  • Offline mode: Install with `--offline` to disable syncing while retaining local history.
  • Rebuild local DB: Use `hishtory init --force <secret>`.
  • Inspect logs: Tail `~/.hishtory/hishtory.log` for detailed error messages.
Security: Secret keys live only on clients. Disable syncing temporarily with `hishtory syncing disable` when handling sensitive work.
